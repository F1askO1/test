# Карта и GPS 2.0: результаты и границы готовности

База 107d217, ветка feat/slopemate-ski-map-gps-v2. Существующий backend Windows/Tailscale, Mini App Only, Full Bot, BOT_TOKEN/initData, профили и SQLite сохраняются. Автоматический merge не выполнялся.

## Подтверждённые исходные проблемы

- defer у Telegram SDK и константа tg на этапе импорта могли фиксировать отсутствие SDK до авторизованного запроса. Теперь SDK стоит parser-blocking перед module entry, после первого чёрного DOM; отдельный тест задерживает SDK на 600 мс и проверяет заголовок первого /api/me.
- Тёмный CSS-фильтр обесцвечивал геоданные; он удалён. Необоснованный начальный фокус на Красной Поляне заменён обзором России/выбранным курортом/положением записи. Кнопка GPS запрашивает разрешение явно.
- Соседние малые изменения высоты не определяли постепенный спуск. В v2 используется окно и медианы; v1 остаётся для истории.
- Полная перезапись многотысячного localStorage и полный UI-анализ на каждую точку заменены incremental IndexedDB и Web Worker с ограниченной очередью.
- Одинаковые успешные статусы launcher печатались каждые 30 с: теперь печать при изменении/ошибке, сводка раз в 10 минут, журналирование проверок сохраняется.

## Проверки

- `npm run check`: успешно.
- `npm run build`: успешно, TypeScript/Vite/backend. Анализ worker ~8.2 kB, карта lazy-loaded, основной JS ~285 kB до gzip. Новые UI-фреймворки/платные API не добавлены.
- `npm test`: **63 passed**, 0 failed/skipped. Включены прежние расчёты/API/SQLite/Telegram recovery, v2 окна/gaps/остановки/GPX, matching/ETA, native pairing/revoke/expiry/retry, v1 history, реальный offline CLI import в временной папке и защита старого каталога от ошибочного ответа.
- Playwright Chromium: **14 passed**. Прежние GPS/GPX/profile/history сохранены; светлая карта/слои/поиск на 375×812, 390×844, 430×932, SDK race, IndexedDB recovery без localStorage, кандидат/подтверждение lift и ETA, safe areas 393 px, reduced motion и отсутствие горизонтального overflow.
- 12 000 синтетических точек без геометрии: тест прошёл с запасом относительно лимита 5 с на этой cloud-машине; физический iPhone benchmark не выполнен.
- Info.plist успешно прочитан XML-парсером. **Это не сборка Swift/Xcode.** Нативный код ещё требует компиляции, signing и проверки устройства.

## Синтетическая оценка, не полевая точность

`npm run gps:evaluate` создаёт artifacts/gps-v2/synthetic-evaluation.json. На одном идеализированном demo-треке из 181 точки: 2 спуска; edge precision/recall/F1 для descent 0.9667, для ascent 0.9333. Предсказанный ETA на отдельной идеальной полилинии ~430 с, математическая абсолютная ошибка ~0 с. Нулевая ошибка здесь следует из одинаковой модели движения/геометрии и **не доказывает точность ETA в горах**. Реальные precision/recall/F1, относительная ошибка ETA и расход батареи неизвестны.

## Что ещё не принято

1. **Реальная карта России**: импорт заблокирован network policy. Исходный каталог 0/0/0; полный каталог, классификация конкретных курортов и фактический рельеф не подтверждены. 09_UPDATE_MAPS и offline import реализованы; после разрешённой загрузки проверить coverage.json и контрольные 17 названий. Подробности: RUSSIA_RESORT_COVERAGE_RU.md.
2. **Поставщик рельефа**: первичный OpenTopoMap README называет raster устаревающим. Есть переключение на OSM, но долгосрочная доступность terrain не гарантирована. Не используем запрещённые сторонние тайлы OpenSkiMap.
3. **iPhone background**: web-only не гарантирует получение координат при блокировке. Native companion подготовлен исходниками, но не собран/не испытан. Нет утверждения о готовой многочасовой фоновой записи. См. BACKGROUND_GPS_TEST_REPORT_RU.md.
4. **Windows/Karing/Tailscale и реальная сеть**: автоматизация выполнена на Linux, существующий Funnel не менялся. Двойной щелчок BAT, реальный токен/SDK внутри Telegram, tiles/маршруты российских курортов, 60+ минут native и батарея требуют ручной проверки.
5. **Не реализовано в этой ветке**: адаптер GeoJSON OpenSkiData, современные vector terrain/3D/satellite, полная национальная верификация, trained HMM, DEM, автоматический relaunch iOS после force quit. Интерфейс не выдаёт эти функции за доступные.

Итог: код и автоматические сценарии готовы к ревью, но полные критерии карты России и фоновой записи **не выполнены** до получения данных и реальной нативной приёмки. Новая инфраструктура/домен/VPS не требуются и не создавались.
