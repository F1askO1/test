# SlopeMate: обновить ZIP и запустить на Windows

Для текущего сценария нужны только Windows 10/11, Node.js 24 с npm и **уже разрешённый и настроенный Tailscale Funnel** на `127.0.0.1:3001`. Git, сервер и покупка домена не требуются. Сам launcher не открывает новый публичный доступ и не меняет настройки организации.

## Обновление без Git

1. В работающем launcher введите **q и Enter**. Остановите старые ручные `npm start`/локальный dev-сервер в их исходных окнах. Не запускайте две версии на порту 3001.
2. Сделайте резервную копию всей папки SlopeMate. Особенно сохраните `.env`, собственную папку `map-data` (если уже импортировали карты) и каталог `data` с SQLite и имеющимися `-wal`/`-shm`. Пока копируете базу, сервер должен быть остановлен. Не удаляйте старую копию до проверки истории.
3. Скачайте ZIP именно ветки `feat/slopemate-ski-map-gps-v2` через GitHub → Code → Download ZIP. Распакуйте в отдельную папку и убедитесь, что там есть `SlopeMate.bat`.
4. Скопируйте сохранённые `.env` и **весь `data`** в новую папку рядом с BAT. В чистом ZIP этих личных файлов нет. Не заменяйте их `.env.example` и не объединяйте две разные базы. Перенесите прочие собственные локальные настройки, если они были.
5. Запустите `01_INSTALL.bat` двойным щелчком. Он установит недостающие зависимости и соберёт актуальный frontend/backend. Предварительный ручной `npm ci` больше не нужен. Установщик стартует без dotenv и любых проектных npm-зависимостей.
6. После проверки нового приложения используйте только новую папку. Не удаляйте резервную копию сразу.

Можно обновить файлы внутри прежней папки, **только явно исключив `.env`, `data` и свои настройки из замены**. Более безопасный способ для новичка — отдельная новая папка и перенос личных файлов по шагам выше. Автоматического скачивания/перезаписи или git reset нет.

Если Node.js не установлен, установите официальный **Node.js 24 LTS с npm**, затем откройте launcher заново. Git устанавливать не надо.

## Первый запуск Mini App Only — основной режим рабочего ПК

Откройте `05_EDIT_ENV.bat`: это обычный Блокнот. Сохраните имеющиеся BOT_TOKEN, DEPLOYMENT_ID и DIAGNOSTICS_TOKEN. Проверьте настройки:

```dotenv
NODE_ENV=production
DEV_AUTH=false
HOST=127.0.0.1
PORT=3001
DATABASE_PATH=./data/slopemate.sqlite
BOT_TOKEN=ваш_токен_только_в_локальном_файле
BOT_ENABLED=false
RUN_TARGET=local
PUBLIC_ENDPOINT_MODE=external
APP_URL=https://имя-устройства.ваш-tailnet.ts.net
TRUST_PROXY=loopback
TELEGRAM_PROXY_URL=
```

Пример домена нужно заменить своим **уже работающим адресом Funnel**, а существующий правильный APP_URL оставить. Секретный токен берётся у официального @BotFather, записывается только в .env и не отправляется в чат. Даже без polling он необходим серверу для проверки подписи Telegram initData. Токен должен принадлежать тому боту, чьей кнопкой открывается приложение.

`TRUST_PROXY=1` тоже поддерживается для одного известного proxy-hop. `loopback` доверяет только локальному reverse proxy; `true` без ограничений запрещено. Для Funnel с loopback это устраняет ERR_ERL_UNEXPECTED_X_FORWARDED_FOR без доверия всему интернету.

Затем запустите **`04_TELEGRAM.bat`** или `SlopeMate.bat` → **3. Mini App Only**.

Launcher:

- проверит зависимости, порт, приватную конфигурацию и актуальность сборки;
- при изменении lockfile установит зависимости, при изменении исходников пересоберёт dist;
- прочитает `tailscale funnel status --json`, если CLI доступен; не создаст/не пересоздаст Funnel;
- определит APP_URL из существующего Funnel, если поле пустое; непустой конфликтующий адрес не заменит молча;
- запустит HTTP + SQLite без polling, проверит локальный и публичный health и deployment identity;
- покажет: **«Mini App готово. Telegram polling отключён»**.

В этом режиме недоступный `api.telegram.org` или SOCKS-прокси **не мешает запуску**. `/start`, `/help`, `/stats` при выключенном боте не отвечают — это ожидаемо. Открывайте приложение через заранее настроенную кнопку меню.

В @BotFather используйте `/setmenubutton`, выберите своего бота, задайте свой Funnel HTTPS URL и название «Открыть SlopeMate». Если кнопка уже работает и адрес прежний, повторная настройка не нужна. Нельзя заменять серверную авторизацию на DEV_AUTH=true ради открытия страницы.

## Full Bot — только при разрешённом доступе к Telegram

Запустите **`08_FULL_BOT.bat`** или меню → **4. Mini App + Full Telegram Bot**. Это явный выбор polling для текущего запуска, независимо от безопасного значения BOT_ENABLED=false в .env. Токен в файле не меняется.

Если нужен разрешённый SOCKS5, задайте реальный адрес в .env:

```dotenv
TELEGRAM_PROXY_URL=socks5h://127.0.0.1:ваш_порт
```

Не считайте порт с другого ПК действительным для рабочего компьютера. При блокировке Telegram организацией не обходите политику сети; используйте Mini App Only. Launcher не включает TUN/VPN, не меняет DNS/маршруты и не обещает доступности API по одному лишь наличию токена.

В Full Bot команды и меню обслуживаются grammY с прежними исправленными тайм-аутами, backoff/jitter и восстановлением. Сбой API не закрывает HTTP. Второй poller не запускается поверх первого.

## Tailscale и диагностика

Меню → **5. Проверить Tailscale и HTTPS** читает состояние и проверяет `/api/health`. Если CLI не найден, укажите необязательный `TAILSCALE_PATH` (обычно `C:\Program Files\Tailscale\tailscale.exe`). Не нужно повторять `tailscale funnel --bg 3001` при каждом старте.

Первоначальное разрешение публичного Funnel выполняется **отдельно самим пользователем/администратором**, только если организация это допускает. При отсутствии настроенного Funnel сначала получите разрешение и выполните официальную настройку Tailscale. Команда `tailscale funnel --bg 3001` — ручной этап первоначальной настройки, а не действие launcher. Здесь её агент не выполнял. Не предполагается, что Funnel доступен во всех tailnet/тарифах/сетях.

`07_DIAGNOSTICS.bat` показывает статусы без второго polling. `/api/health` проверяет HTTP; `/api/status` — безопасную сводку, deployment ID и **buildId**. Подробный `/api/diagnostics` закрыт отдельным токеном. .env, база, node_modules, dist и logs исключены из Git.

Build ID также виден внизу интерфейса. Если после ZIP виден прежний интерфейс, остановите старый сервер, запустите новый BAT и проверьте build ID. Production обслуживается из **dist**, а не прямо из исходников. Не запускайте npm start из другой старой папки. Если WebView сохранил старую страницу, закройте Mini App и заново откройте кнопкой Telegram.

## Проверка с iPhone

1. Откройте свой Funnel URL `/api/health` через мобильный интернет: должен вернуться `{"ok":true}`.
2. Откройте Mini App кнопкой внутри Telegram. Должны появиться чёрная заставка, затем новый интерфейс.
3. Профиль и история должны сохраниться. Демо всегда помечено и не входит в реальные рекорды.
4. Проверьте запись на улице с разрешённым GPS. В фоне/при блокировке непрерывная запись не гарантируется. При сетевой ошибке черновик остаётся на том же устройстве и HTTPS origin.
5. `/api/me` в обычном Safari без initData должен отвечать 401: это защита, а не неисправный Funnel. Истёкшую Telegram-авторизацию восстанавливают переоткрытием через бота.

Физический iPhone, реальный Tailscale Windows и ваша сеть агентом не проверены. Автоматические проверки используют Chromium и фиктивные данные.

## Остановка и ограничения

В окне launcher введите **q + Enter** или Ctrl+C. Завершаются только его HTTP/бот-процессы; Tailscale/Funnel не выключаются и не перенастраиваются. Закрытие окна крестиком не заменяет штатную остановку. Чужие Node/Tailscale процессы не убиваются.

Сеть и включённый ПК необходимы для Funnel. Уже имеющийся адрес не обещается вечно доступным или неограниченным: действуют условия Tailscale и политики организации. Покупка VPS или домена для этого сценария **не требуется**. Исторические deployment-файлы сохранены, но launcher не переносит туда данные и не предлагает миграцию.

## Светлая карта и GPS 2.0

Сборка этой ветки сохраняет старые сессии с анализом v1. Новые записи используют v2, а web-черновик мигрирует из localStorage в IndexedDB на том же HTTPS origin. Не очищайте данные Telegram WebView и не меняйте адрес Funnel, пока незавершённая запись не синхронизирована. После перезапуска дождитесь восстановления черновика, затем нажмите «Возобновить GPS».

Сама карта теперь светлая; интерфейс вокруг остаётся чёрным. «Карта» → поиск/регион/курорт, «Слои» → рельеф, трассы, подъёмники, свой трек. Цвета сложности берутся только из тегов OSM. Текущее положение запрашивается отдельной кнопкой. Ручное движение карты отключает слежение. Неизвестная трасса/подъёмник не придумываются.

**Первичная поставка этой ветки не содержит импортированных российских геоданных:** cloud network policy запретила источник. Не считайте пустой каталог полным покрытием России. Для наполнения в разрешённой сети после 01_INSTALL запустите **09_UPDATE_MAPS.bat**. Это отдельная операция, не обычный запуск, не требует покупки сервера, может занять несколько минут. При ошибке старая подготовленная карта сохраняется. Альтернатива — получить готовую map-data/ на другом разрешённом компьютере и перенести её целиком. Подробности и отчёт: RUSSIA_RESORT_COVERAGE_RU.md. Не заменяйте собственную наполненную map-data пустым индексом из ZIP.

Базовые тайлы OpenTopoMap/OSM загружаются телефоном; без интернета подложка может отсутствовать даже при доступном локальном наборе трасс. Массовая загрузка тайлов не выполняется. После импорта перезапустите/переоткройте Mini App для нового каталога; SQL-пользовательские данные не меняются.

09_UPDATE_MAPS не использует прокси Telegram автоматически. Если рабочая сеть запрещает Overpass, согласуйте доступ или подготовьте данные отдельно; launcher не меняет сетевую политику. Параметр SKI_DATA_PATH в .env позволяет выбрать уже готовую локальную папку.

Мониторинг launcher сохраняется: повтор одинакового успешного статуса не печатается каждые 30 секунд, изменения/ошибки выводятся сразу, сводка примерно раз в 10 минут. Полный технический журнал остаётся в logs без токенов.

## Запись при блокировке iPhone

Обычный Mini App не гарантирует новые координаты в фоне. IndexedDB сохраняет **уже полученные** точки, не заменяет Core Location. Для многочасовой фоновой записи подготовлен отдельный экспериментальный iOS-проект `ios/SlopeMateRecorder`.

Нужны Mac/Xcode, signing и установка на реальный iPhone. Это не обязательное условие обычного web-режима и не покупка VPS. После установки: Профиль → привязать установленный рекордер → подтвердить домен → начать в companion → завершить и дождаться sync → открыть историю Telegram. Экран Core Location может показывать системный индикатор. Полный сценарий и ограничения: BACKGROUND_GPS_ARCHITECTURE_RU.md, BACKGROUND_GPS_TEST_REPORT_RU.md. Нативная сборка и блокировка на 60 минут агентом **не проверены**.
