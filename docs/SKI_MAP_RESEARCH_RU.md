# Исследование карт SlopeMate — 5 ноября 2026

Исходная версия 107d217. Цель: светлая географическая карта внутри существующего тёмного интерфейса. Референс пользователя — ориентир UX, не источник геометрии или графики.

## Проверенные первоисточники и ограничения доступа

GitHub OpenSkiMap и OpenSkiData Processor изучены непосредственно. В About.tsx OpenSkiMap **прямо запрещено использование tiles.openskimap.org сторонними приложениями**; этот endpoint не подключаем. Processor README подтверждает выгрузки GeoJSON и MVT, отдельный этап обработки/кластеризации и необходимые внешние сервисы высоты. Processor использует OSM и Skimap.org; лицензия кода не заменяет лицензию данных. Не копируем его код.

- https://github.com/russellporter/openskimap.org/blob/master/src/components/About.tsx — acceptable use, выгрузки.
- https://github.com/russellporter/openskidata-processor — README, геометрии, поля piste:difficulty, aerialway:duration, станции и связи skiAreas.
- https://www.openskidata.org/ — желательный готовый источник; прямое открытие в среде запрещено network policy (403).

Значительная часть официальных сайтов запрещена политикой этой облачной среды. Это не доказательство их недоступности у пользователя. Не обходили ограничения, не меняли сеть. Ссылки выше приведены для проверки, а не как утверждение успешной загрузки каждой страницы. Фактические геоданные России нельзя подменять нарисованными трассами.

## Выбор

Leaflet + компактный набор на курорт: уже используется, не требует WebGL и нового фреймворка, хорош для тысяч линий при Canvas rendering. MapLibre/MVT предпочтителен при национальном отображении всей геометрии, но это потребует собственных тайлов/стиля/хостинга. Сейчас каталог лёгкий, геометрия загружается по требованию с того же backend. Overpass не вызывается телефоном или при обычном BAT-запуске.

Базовая карта: стандартная светлая OSM; отдельный рельеф OpenTopoMap с атрибуцией OSM/SRTM/OpenTopoMap CC-BY-SA (https://github.com/der-stefan/OpenTopoMap). Нет CSS-фильтра. Нет массовой загрузки/офлайн-кэша тайлов. Доступность внешних тайлов не гарантирована; ошибки отделены от GPS/локальной геометрии. Спутниковый слой не добавлен без проверенного разрешённого поставщика. Псевдо-3D, несуществующий рельеф и чужие тайлы OpenSkiMap не используются.

Реальные piste:difficulty из OSM отображаются beginner=зелёный, easy=синий, intermediate=красный, advanced=чёрный, expert/freeride/unknown — особое нейтральное обозначение, без назначения официального цвета по уклону. При наличии документированного локального цвета импорт сохраняет его происхождение. Теги OSM — общественная разметка, не официальная сертификация и не оперативный статус открытия.

## Данные и обновление

Отдельный импорт OSM Overpass JSON с out geom, либо явный сетевой запуск из разрешённой среды. Наборы нормализуются, содержат источник/дату/ODbL, исходный OSM ID, длины по геометрии, станции, неизвестные поля. Общий каталог не доказывает полноту трасс. Установленный набор хранится независимо от SQLite. Отчёт считает actual imported objects и классифицированные линии. Автоматического обещания ежедневной актуальности нет: частота определяется явным запуском обновления.

## GPS и ETA

Для iPhone выбран детерминированный конечный автомат с временными окнами и гистерезисом. HMM без размеченной выборки даёт неоправданную сложность; Kalman требует корректной модели шума и может срезать повороты; DEM добавляет внешний источник и не измеряет реальную высоту пользователя. Консервативная сглаженная тенденция высоты выделяет направление; неопределённость не превращается в перепад. Неизвестная точность GPX допускает только предварительную классификацию устойчивой тенденции, без достоверного вертикального рекорда.

Map matching использует проекцию на каждый сегмент, накопленную длину, точность GPS, последовательное продвижение, альтернативные соседние линии и подтверждение подъёма. ETA основан на продвижении по линии, а не прямом расстоянии; при остановке/неясном направлении не выдаётся. Нужна реальная размеченная выборка для precision/recall/F1 и ошибки ETA; синтетические проверки доказывают инварианты, не полевую точность.

## Дополнительная проверка OpenTopoMap

Прочитан первичный https://github.com/der-stefan/OpenTopoMap/blob/master/README.md : включает SRTM/OSM, разрешает встраивание с условиями about#verwendung и CC-BY-SA, **помечает старые raster tiles устаревающими и сообщает о переходе на векторные**. Поэтому этот слой не заявлен долгосрочно гарантированным поставщиком рельефа. В UI при ошибке доступен переход на светлую OSM; доступность реального рельефа необходимо проверить на устройстве. Для постоянного современного vector terrain далее потребуется согласованный стиль/поставщик либо собственная подготовка, не несанкционированное подключение tiles.openskimap.org.
