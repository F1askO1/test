# Ручная приёмка

## Telegram и безопасность

- `.env`: настоящий BOT_TOKEN, HTTPS APP_URL, DEV_AUTH=false, NODE_ENV=production. Build → start. В логе должны быть API ready и Telegram bot started.
- Личный чат: /start → приветствие → кнопка открывает Mini App; меню тоже открывает актуальный адрес. /help отвечает. /stats сначала сообщает об отсутствии данных, затем считает реальные записи без демо.
- Mini App показывает имя/аватар, профиль сохраняется. Прямой браузер без initData получает отказ API. Запросы с чужим ID пользователя в body не меняют владельца.
- Запустите второй Telegram-аккаунт: его история пуста, чужой UUID возвращает 404.
- DEV_AUTH=true + NODE_ENV=production: запуск обязан завершиться ошибкой. Не вводите боевой токен в команды для тестов и логи.
- Откройте Mini App через час: ожидается отказ истёкшего initData и просьба открыть заново. Проверьте сохранность локального черновика.

## iPhone Telegram (и отдельно Android)

- Проверьте ширины 320–430 px, safe area, нижнюю навигацию, клавиатуру, длинное имя, профиль и все экраны. Нет горизонтальной прокрутки. Данные читаемы на улице.
- Отказ в GPS → понятная ошибка; включение разрешения и повторный запуск → свежие точки. В помещении/при плохой точности предупреждение.
- На улице запишите пеший маршрут; есть линия и скорость. На месте дистанция не должна быстро расти. Пауза/возобновление не соединяет промежуток.
- Заблокируйте телефон / сверните Telegram на минуту. Не ожидайте фоновой записи. Вернитесь: есть предупреждение/разрыв, приложение не рисует отсутствующий участок.
- Принудительно закройте WebView и повторно откройте: восстановите черновик, продолжите/сохраните. Отдельно проверьте очистку localStorage: восстановление после неё невозможно.
- Попробуйте Telegram LocationManager на поддерживаемом клиенте; подтвердите запросы. В старом клиенте приложение должно сообщить о недоступности, не подменять GPS демо.
- Отключите сеть при уже открытом приложении: черновик остаётся. Попытка завершить сообщает ошибку. После включения сети повторно сохраните, убедитесь, что запись одна.
- Проверьте реальный GPX с iCloud Drive/Files, пример sample.gpx, плохой XML, отсутствие времени, файл >5 МБ. Маршрут не соединяет разные trkseg.
- Демо отдельно от реальных показателей. Редактирование профиля и история переживают перезапуск Node с тем же DATABASE_PATH. Удаление требует подтверждения.
- Карта: масштаб/перетаскивание, атрибуция OSM, начало/конец, выбор спуска на демо. При недоступных тайлах данные трека не должны теряться.

Автоматический Playwright использует эмуляцию размера экрана и искусственные координаты Chromium, не доказывает работу GPS в iOS WebView. Бот-тест использует mock API, не подтверждает реальные команды в Telegram. Эти пункты требуют физического устройства, токена и HTTPS.
