# Приёмка фоновой записи iPhone

## Выполнено автоматически

Проверены web IndexedDB/legacy recovery, gaps, авторизация, одноразовая привязка, истечение кода, отзыв ключа, UUID retry, сохранение v1 истории. Автоматические GPS — синтетика/Chromium, не реальные спутниковые измерения. Нативный Swift **не собран и не запущен**: Mac/Xcode/signing/физический iPhone отсутствуют. Unit tests сервера не доказывают фоновую запись или работу Keychain.

## Обязательная реальная матрица — пока НЕ ПРОЙДЕНА

На iPhone фиксируйте модель/iOS/Telegram, разрешения, full/reduced accuracy, время, заряд, температуру и network mode. Сравните timestamps и количество точек, максимальный gap, принятые сервером данные; не оценивайте непрерывность только по нарисованной линии. Измерьте 60–120 минут с блокировкой и несколько циклов сети. Энергопотребление: заряд/час, нагрев, Xcode Instruments Energy Log на companion, один одинаковый маршрут для сравнения. Пока нет численного battery report.

Без этой матрицы нельзя заявить, что многoчасовой фоновый трекинг готов к эксплуатации. Для полноценной приёмки нужен доступ к Apple tooling/устройству; это внешняя зависимость, которую облачный код не заменяет.
