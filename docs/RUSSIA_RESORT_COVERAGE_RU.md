## Подготовленный воспроизводимый импорт

`09_UPDATE_MAPS.bat` выполняет отдельную явную загрузку OSM России и нормализацию. Требуются ранее установленные npm-зависимости и разрешённый доступ к Overpass. Он не запускается автоматически из основного launcher и не меняет Tailscale/Telegram/SQLite. Источник — https://overpass-api.de/api/interpreter, запрос выбирает российскую административную область ISO3166-1=RU и winter_sports/downhill/aerialway. Один ограниченный запрос с timeout, без интенсивных повторов. Публичный Overpass может отказать по нагрузке; не пытайтесь обходить лимиты.

Альтернатива на машине с разрешённой сетью:

```cmd
npm run maps:fetch
npm run maps:import -- artifacts/maps/russia-overpass.json
```

Или импортируйте уже полученный **Overpass JSON с out tags geom**:

```cmd
npm run maps:import -- C:\Downloads\russia-overpass.json
```

Можно перенести готовую папку map-data с разрешённого компьютера. GeoJSON OpenSkiData **не принимается этим адаптером как Overpass JSON**: его формат исследован, но отдельный адаптер OpenSkiData пока не реализован. Не переименовывайте произвольный GeoJSON в Overpass JSON.

Импорт ограничивает вход 64 MiB/200 000 объектов, проверяет координаты, отбрасывает пустые геометрии. Список курортов составляется из реальных OSM winter_sports. Линии связываются по bounding box или близости до 4 км: **это предварительная принадлежность, не официальная граница**. Линии без подходящего курорта считаются unassigned. Отношения с неполной геометрией и курорты без winter_sports могут отсутствовать. Актуальные статусы открытия не выводятся. Станции показываются только из реальных узлов OSM на линии, а не дорисовываются на её концах. Верх/низ не назначаются без данных.

Каталог переключается атомарно после записи версионных файлов; предыдущий индекс сохраняется. Одновременный импорт блокируется .import.lock; после аварии сначала убедитесь, что импортёр остановлен, затем удалите только этот lock. Не запускайте два импортёра. Старые наборы автоматически не удаляются. Наборы валидируются сервером и загружаются по одному курорту, не вся Россия в WebView. Большие пакеты >12 MiB на курорт требуют отдельного разбиения до использования.
