# Smart Lift Tracking — экспериментальный прогноз

Проекция вычисляет ближайшую точку **на сегменте полилинии**, накопленную длину вдоль всех сегментов и остаток до следующей известной станции по направлению. Расстояние по прямой до станции вместо длины канатной дороги не используется. Неизвестная промежуточная станция не выдумывается: тогда цель — конец известной линии.

Для кандидата нужны минимум 4 точки/15 секунд, accuracy ≤30 м, близость к линии, последовательное продвижение, отсутствие gaps, допустимая скорость ≤15 м/с и известное направление либо подтверждённый измеренный подъём. Несколько подходящих подъёмников означают unknown. Для подтверждения нужны ≥25 с, ≥35 м продвижения и положительная измеренная тенденция высоты, превышающая точность. Это намеренно консервативно: без высоты можно остаться кандидатом, даже находясь в кресле. Движение вниз рядом с канатной дорогой не подтверждает lift.

Состояния карточки: кандидат, подтверждённое движение, остановка, приближение, у станции. Неопределённость скрывает карточку. Последние 90 секунд (максимум 40 точек) дают устойчивость к единичному смещению. Это оконная эвристика, не обученная вероятностная модель. Краткие ошибки могут по-прежнему скрывать/возвращать карточку — полевые настройки гистерезиса ещё нужны.

ETA — остаток полилинии / среднее продвижение вдоль линии за окно. Число выдаётся только после подтверждения и скорости ≥0.8 м/с. При отсутствии продвижения на последних ≥10 с ETA скрывается, статус — остановка. aerialway:duration (простое число минут) сохраняется и показывается как справочная продолжительность из OSM, **не подставляется как текущая скорость**. ETA пока не смешивает source duration с измерением, чтобы не выдавать непроверенную оценку за точную.

UI использует «~N мин», «экспериментальный прогноз», остаток метров и progress. Можно скрыть карточку. Это не подсказка безопасного схода и не оперативный статус работы подъёмника. Реальное время до выхода определяется правилами курорта и станцией; слепо полагаться на приложение нельзя.

Синтетический тест проверяет геометрию, направление, остановку, низкую точность и отсутствие данных. Полевая абсолютная/относительная ошибка ETA неизвестна. Для измерения нужны реальное время отправления/прибытия и GPS с допустимой лицензией/согласием. Составьте таблицу predicted-vs-actual по нескольким позициям и типам подъёмников; отдельно учитывайте остановки, параллельные трассы и промежуточные станции.
