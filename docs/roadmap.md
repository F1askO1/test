# Следующий этап

1. Сначала собрать реальные добровольно предоставленные треки iOS/Android, оценить фильтрацию, потери данных, время батареи. Улучшить высотную классификацию с окном и уверенностью. Добавить версию алгоритма и миграции для пересчёта.
2. Friends: отдельная таблица запросов/дружбы с двусторонним подтверждением. Telegram startapp invite — случайный одноразовый токен, а не Telegram ID. Сервер проверяет пользователя через ту же initData. Защита от массовых запросов.
3. PublicStats и настройки приватности отдельно от сырых GPS. Публиковать только агрегаты по явному согласию; история и координаты по умолчанию остаются личными. Демонстрации исключаются на уровне запросов.
4. Leaderboards: сезон, вид спорта, дистанция / скорость; пометка GPS vs GPX, минимальные требования качества, античит. Не смешивать импорт и подтверждённые GPS-рекорды. Результаты не являются сертифицированными.
5. Achievements: независимые правила и таблица user_achievements с уникальностью user + achievement + season. Повторная обработка сессии не выдаёт достижение дважды.
6. Live sharing: отдельное согласие, срок истечения и мгновенное отключение; серверная проверка активного разрешения на каждый запрос. Только друзья, уменьшенная точность по умолчанию, короткий TTL последней позиции, никаких публичных GPS-ссылок. Не обещать фоновой доставки.
7. После роста: миграции схемы с резервными копиями, удаление аккаунта и выгрузка данных, настройки хранения, мониторинг без координат/токенов, поставщик тайлов с подходящими условиями. Переход на PostgreSQL только при реальной потребности; микросервисы пока не нужны.
