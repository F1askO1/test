# Карта Домбая: читаемость и отдельные панели

## Изменения

Экран «Карта» теперь содержит компактный выбор курорта, кнопку ⓘ, карту и нижнюю навигацию. Заголовок страницы, слоган, сезон, постоянная легенда, описание источников и список сохранённых маршрутов больше не занимают место на этом экране. Сохранённые записи доступны в разделе «Прогресс». Предупреждения о сети и активной записи сохранены.

- Нажмите название курорта: откроется поиск курорта/трассы, фильтр региона и выбор курорта.
- Нажмите ⓘ: откроется информация о курорте с количеством участков, подъёмников, классификацией, датой, источником, легендой и оговорками OSM.
- «Слои» открывает настройки подложки, трасс, подъёмников и своего трека.
- Выбор трассы открывает отдельную карточку. Панели поддерживают закрытие, Escape, удержание и восстановление фокуса.

### Линии

| Масштаб Leaflet | Трассы, CSS px | Подъёмники, CSS px |
| --- | ---: | ---: |
| меньше 14 | 1,05 | 0,8 |
| 14–15,5 | 1,55 | 1,05 |
| от 16 | 2,1 | 1,3 |

Убрана широкая белая обводка каждого участка. Узкая подложка остаётся только у чёрных трасс на близком масштабе и у выбранного объекта. Выбор добавляет 1,1 px. Подъёмники — серый пунктир под трассами; станции появляются с масштаба 15. Цвета сложности сохранены. Увеличенная область нажатия Canvas (7 px допуска) позволяет выбирать тонкие линии пальцем. Начальный масштаб вписывает весь реальный bbox с небольшим отступом; геометрия не обрезается и не переписывается.

Убран SVG-флаг из стандартной подписи Leaflet через `attributionControl.setPrefix`. Ссылки Leaflet, OpenStreetMap и лицензия подложки сохранены.

## Настоящий пакет и изоляция

Использован присланный `dombay.slopemap`, подготовленный пользователем из региональной выгрузки Geofabrik/OSM Северного Кавказа. SHA-256 пакета:

`4d236835cbe08e3dfcff4031e17c12e9507761b5feac01442947d5b14cd9a6f3`

Пакет проверен штатной командой `maps:package -- inspect` и импортирован только в `artifacts/map-design/map-data`. SHA-256 установленного JSON совпадает с записью пакета:

`b4cf6e169f8056814e0e2bb4a570fbd262a9c23d39259d62bf5cbd7bb4bdb171`

Это **136 геометрических участков трасс**, **13 линий подъёмников**, **131 классифицированный участок (96,3%)**. Не число официальных трасс. Сложности: 65 easy, 62 intermediate, 3 novice, 1 advanced, 5 unknown. В 149 объектах — 1787 координат. Качество `usable-partial`, принадлежность по поисковой области (`search-window`); официальная принадлежность и открытие не подтверждены. Дата набора: `2026-11-05T18:57:40.802Z`.

Исходный пакет, региональный PBF и данные не включены в коммит. Рабочие `map-data`, `.env`, пользовательская SQLite, авторизация, GPS-модуль и Windows launcher не менялись. Браузерный сервер использует отдельный порт 3099, SQLite `:memory:` и явный тестовый путь; его локальная авторизация не меняет production-конфигурацию.

## Проверки

`npm run check`, `npm run build`, `npm test` (79 тестов) проходят. Браузерные проверки новой карты выполнены в Chromium с мобильными размерами 375×812, 390×844, 430×932: реальный API с пакетом Домбая, открытие карты, размеры полотна, отсутствие прокрутки страницы, поиск настоящего участка, панели, переключение подъёмников, Escape/фокус, отсутствие ошибок JavaScript. Геометрия и API в этих трёх проверках не замоканы. Полный прогон с реальным пакетом: 17 браузерных тестов прошли, один строгий тест тайлов завершился ошибкой, описанной ниже.

Синтетические фикстуры остаются только в существующих отдельных регрессионных тестах `ski.spec.ts`; скриншоты ниже получены не из них.

**Ограничение:** эффективная облачная политика не разрешает хосты картографических тайлов. В трёх UI-проверках запросы тайлов явно отменены (`SLOPEMATE_MAP_OFFLINE=1`) для проверки честного состояния «Подложка недоступна». Строгий тест `dombay-real.spec.ts`, требующий настоящих загруженных тайлов, с реальным пакетом не прошёл: 0 загруженных тайлов за 20 секунд. Его проверки не ослаблены. Эти скриншоты подтверждают рендер настоящих трасс и подъёмников, но **не проверяют топографическую подложку**. На Windows с доступом к провайдеру тайлов и на физическом iPhone это нужно проверить отдельно.

Воспроизведение после сборки (bash, Chromium установлен):

```sh
npm run maps:package -- inspect /path/to/dombay.slopemap
npm run maps:package -- import /path/to/dombay.slopemap artifacts/map-design/map-data
SLOPEMATE_TEST_MAPS="$PWD/artifacts/map-design/map-data" SLOPEMATE_MAP_OFFLINE=1 PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e -- map-readability.spec.ts
```

Для полноценной сетевой проверки запустите `dombay-real.spec.ts` с тем же тестовым путём и без `SLOPEMATE_MAP_OFFLINE`. Не импортируйте данные в пользовательскую базу для этой проверки.

- `frontend/src/Map.tsx`: полотна, стили, слои, выбор, панели, атрибуция.
- `frontend/src/ski/map-style.ts`: проверяемые масштабные стили.
- `frontend/src/ski/MapSheet.tsx`: доступная модальная панель.
- `frontend/src/main.tsx`, `frontend/src/style.css`: компактная структура и мобильная высота экрана.
- `playwright.config.ts`: отдельный путь тестовых карт через переменную окружения.
- `tests/map-style.test.ts`, `tests/browser/{ski,dombay-real,map-readability}.spec.ts`: регрессии и реальный набор.
