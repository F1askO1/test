# Наборы карты

catalog.json — компактный индекс; files связывает безопасный ID с версионным файлом курорта. Обновляется отдельным импортом, не во время открытия карты. OSM — ODbL 1.0, © OpenStreetMap contributors, https://www.openstreetmap.org/copyright . Сохраняйте атрибуцию и условия ODbL при распространении производной базы. Сам код импортера не является лицензией на сторонние данные. Наборы не содержат GPS пользователей.

Исходная поставка не содержит выдуманных трасс: импорт реальных данных заблокирован политикой исходящих соединений данной cloud-среды. Пустой индекс явно отражает это. После разрешённого импорта распространяйте map-data вместе с приложением, отдельно от личного data/SQLite. Не удаляйте собственные наборы при ZIP-обновлении.
