# Проверенный пакет Домбая

`dombay-2026-11-06.slopemap`: публичные данные © OpenStreetMap contributors, ODbL 1.0, https://www.openstreetmap.org/copyright.

Подготовлен штатным импортом из пользовательского Osmium/Geofabrik `resort.osm`, сохранённого в `tests/fixtures/dombay`. 149 исходных объектов, неизменённые координаты; 136 лыжных OSM-частей (107 границ площадей, 29 линейных частей), 13 подъёмников, 131 классификация, 8 собранных площадей.

Сначала обновите код, затем импортируйте пакет существующим меню карт. Старый импортёр не знает новых необязательных полей и может удалить семантику площадей. Пакет не устанавливается автоматически, не содержит `.env`, SQLite, токенов или пользовательских GPS.

Инструкции, ограничения топографии, строгий Windows-тест и SHA-256: `docs/CARTOGRAPHY_SOURCE_RU.md`.
